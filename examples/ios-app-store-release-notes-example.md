# FocusList iOS v4.1.0

**Release Date:** 2026-11-14 | **Audience:** iOS 17+ and iPadOS 17+ users

Interactive Lock Screen widgets and faster iCloud task sync across iPhone and iPad.

## Highlights

- Check off today's tasks directly from your Lock Screen without opening the app.
- iCloud background sync now finishes before the first frame renders.

## New Features

- **Interactive Lock Screen Widgets**: Add the Today widget to complete tasks with a single tap.

## Improvements

- **VoiceOver Rotor Actions for Due Dates**: Swipe up or down on any task to reschedule by one day or one week.

## Bug Fixes

- **Keyboard Overlap on iPhone SE**: Fixed an issue where the Save button hid behind the keyboard in landscape mode.

## Upgrade & Deployment Notes

Available now on the App Store.
