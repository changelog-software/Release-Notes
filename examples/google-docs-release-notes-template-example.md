# ClearDesk Helpdesk v2.9.0

**Release Date:** 2026-11-16 | **Audience:** Support, Product Marketing, Customer Success

Introduces SLA pause rules for pending customer replies and a redesigned ticket merge modal.

## Highlights

- SLA timers now pause automatically when ticket status is Waiting on Customer.
- Ticket merge previews both conversation threads before confirming.

## New Features

- **Automatic SLA Pause Rules**: Configure pause triggers under Settings -> SLAs -> Pause Conditions.

## Improvements

- **Side-by-Side Ticket Merge Preview**: Agents can verify requester, tags, and attachments before merging duplicates.

## Bug Fixes

- **Duplicate Email Notifications on Reopen**: Resolved a webhook race condition when a closed ticket received two replies.

## Upgrade & Deployment Notes

Enabled for all Pro and Enterprise workspaces. Help center article linked in internal brief.
