# LedgerFlow Desktop v5.3.0

**Release Date:** 2026-11-15 | **Audience:** Finance & Operations teams

Adds multi-currency CSV import templates, faster month-end reconciliation, and updated Windows 11 print margins.

## Highlights

- Import multi-currency bank statements using saved column presets.
- Reconciliation batch runs complete in under 4 seconds for 25,000 rows.

## New Features

- **Saved CSV Import Presets**: Map bank columns once and reuse the preset across monthly imports.

## Improvements

- **Faster Month-End Reconciliation**: Indexed ledger matching cuts batch reconciliation time from 14s to 3.8s.

## Bug Fixes

- **PDF Print Margin Clipping on Windows 11**: Fixed right-edge column clipping when exporting A4 statements to PDF.

## Upgrade & Deployment Notes

Run the signed v5.3.0 installer. Existing local ledger databases migrate automatically.

## Known Issues

macOS Sequoia users must grant folder access once on first export.
